# Hotel Bambú Plaza

Sitio web estático para presentar la experiencia del huésped y el panel administrativo del Hotel Bambú Plaza. Esta versión no confirma disponibilidad ni procesa reservas reales.

## Vista local

Sirve la carpeta `dist` con cualquier servidor HTTP estático. Por ejemplo:

```powershell
npx serve dist
```

## Alcance implementado

- Página de inicio y catálogo de habitaciones.
- Detalle de habitación, galería y formulario de solicitud.
- Secciones de contacto y ubicación sin datos de contacto publicados.
- Panel administrativo demostrativo.
- Diseño adaptable y accesible.
